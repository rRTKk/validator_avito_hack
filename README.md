# Команды терминал для работы с валидатором  
```
шаг 1: python test_preprocessing.py - создание + тест препроцесс очистка данных

шаг 2: python test_build_base_dataset.py - создание + тест общего рабочего датасета

шаг 3: python test_folds.py - тест + создание разбиения данных на 3 временных фолда + сохранение для будущей работы

шаг 4: python train_catboost_fold.py название гипотезы - проверка гипотезы на 1 фолде(фолд выбирается в настройках катбуст)
```
## Запуск валидации по 3 фолдам

шаг 5: 

    python run_hypothesis_3folds.py baseline - запуск только baseline
    python run_hypothesis_3folds.py выбранная гипотеза - запуск бейзлайн + выбранная гипотеза

# Удаление полученных данных

```
rm -rf data/processed - убрать шаг 1 и 2

rm data/processed/base_dataset.parquet - удалить шаг 2, оставить 1

rm -rf data/folds - удалить шаг 3, осатвить 1 и 2
```
